# 스마트 버티포트 대시보드

Streamlit에서 단일 드론의 상태, 착륙장 조건과 YOLO FOD 탐지 결과를 확인하는 시뮬레이션입니다. 드론 상태는 직접 설정하거나 시뮬레이터에서 생성합니다.

```text
이미지 업로드 또는 브라우저 웹캠 → YOLO FOD 탐지 → 결과 유효성 확인
유효한 FOD 결과 + 드론 상태 + 사람이 설정한 착륙장 조건
    → 기존 착륙 판단 규칙 → 상태·사유·권고 표시 → 이벤트 CSV
실시간 FOD 탐지 시작 → 탐지 프레임 JPEG + 당시 판단 JSON → 사진 갤러리
```

| 파일 | 역할 |
| --- | --- |
| `vertiport_dashboard/app.py` | 화면, 입력 검증, 착륙 판단 및 이벤트 연동 |
| `vertiport_dashboard/fod_detection.py` | 이미지 업로드 분석과 공유 YOLO 모델 |
| `vertiport_dashboard/video_detection.py` | WebRTC 프레임 추론, 영상 박스 표시, 최신 결과 관리 |
| `vertiport_dashboard/fod_snapshots.py` | 탐지 순간 JPEG·JSON 저장, 이력 조회 및 CSV 연결 |
| `vertiport_dashboard/drone_simulator.py` | 단일 드론 가상 상태 생성 |
| `vertiport_dashboard/event_logger.py` | 이벤트 CSV 저장 및 조회 |
| `smart_vertiport/main.py` | 기존 착륙 가능 여부와 별도 다중 드론 우선순위 알고리즘 |
| `smart_vertiport/landing_policy.py` | 단일 드론의 경고 수준과 권고 조치 |
| `train_model/weights/best.pt` | 클래스 `{0: "FOD"}`의 팀 YOLO 가중치 |

## Windows 설치 및 실행

저장소 루트에서 PowerShell로 실행합니다. 64비트 Python 3.12를 권장합니다. Python 3.14를 쓰는 경우 Windows용 PyTorch와 PyAV 휠이 제공되는지 설치 결과를 확인하세요. 앱은 Streamlit, Ultralytics 및 영상 연결용 streamlit-webrtc를 사용하며, PyAV와 aiortc는 영상 패키지의 의존성으로 설치됩니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\vertiport_dashboard\requirements.txt
.\.venv\Scripts\python.exe -m streamlit run .\vertiport_dashboard\app.py
```

이미 만든 가상환경을 사용한다면 첫 명령은 건너뜁니다. 브라우저에서 `http://localhost:8501`을 열고, 종료는 터미널에서 Ctrl+C를 누릅니다. 모델은 먼저 `train_model/weights/best.pt`를 찾고, 없으면 `vertiport_dashboard/models/best.pt`를 확인합니다. 두 경우 모두 팀의 `smart_vertiport` 모듈이 있는 저장소에서 실행합니다.

## FOD 탐지

첫 화면은 실시간 영상 분석으로 열립니다. 상단 왼쪽에서 카메라를 제어하고, 오른쪽에서 착륙 판단, 배터리·고도, FOD 수, 긴급 상태 및 권고 조치를 확인합니다. 바로 아래에는 FOD 분석 결과와 착륙 판단 근거가 있으며, 그 아래에 최근 이벤트와 사진 갤러리가 표시됩니다.

### 이미지 업로드

**이미지 업로드**를 선택한 다음 JPG, JPEG 또는 PNG를 올립니다. **최소 탐지 신뢰도**를 선택하고 **FOD 탐지 실행**을 누르면 원본, 바운딩 박스가 표시된 이미지, FOD 개수와 최고 신뢰도를 볼 수 있습니다. 분석 완료 후 60초 동안 결과를 사용합니다. 이미지 또는 신뢰도 변경, 모드 전환, 분석 오류나 결과 만료 후에는 다시 분석해야 합니다.

### 실시간 영상 분석

**실시간 영상 분석**을 선택하고 WebRTC의 **START**를 누른 뒤 브라우저 카메라 권한을 허용합니다. 영상에 FOD 박스가 표시되고 탐지 개수, 최고 신뢰도, 착륙 판단이 약 1초마다 갱신됩니다. **STOP**으로 종료합니다. 카메라 권한을 거부했다면 사이트 권한을 수정한 뒤 다시 시작하세요.

**영상 분석 설정**의 기본값은 분석 간격 0.5초, 입력 크기 640픽셀, 최소 신뢰도 0.25, 유효시간 3초입니다. CPU에서 한 번에 한 프레임을 추론합니다. 추론 중 들어오는 프레임은 쌓지 않으며, 추론이 끝난 뒤 새로 들어오는 프레임을 사용합니다. 영상 박스는 유효한 최신 추론을 바탕으로 표시되므로 움직임이 빠르면 화면상 위치에 시차가 생길 수 있습니다.

최신 프레임 수신 시각과 추론 완료 시각을 별도로 관리하고, 분석에 사용한 프레임의 수신 시각도 유효시간 내인지 확인합니다. 연결 전, 프레임 수신 중단, 추론 오류, 결과 만료 또는 스트림 종료 시 판단을 보류합니다. FOD 0개는 정상적으로 끝난 유효 분석이 있을 때만 표시됩니다. 모드를 전환하면 이전 입력의 결과가 초기화됩니다.

브라우저 카메라에는 localhost 또는 HTTPS가 필요합니다. 원격 서버에서 실행하거나 방화벽과 NAT를 통과하는 경우 WebRTC ICE 설정에 맞는 STUN/TURN 서버가 필요할 수 있습니다. 사용법은 [streamlit-webrtc 공식 문서](https://github.com/whitphx/streamlit-webrtc#serving-from-remote-host)를 참고하세요.

## 드론 상태와 착륙 판단

- **직접 설정**에서 배터리, 고도, 긴급 상태, 착륙 요청을 지정합니다.
- **드론 시뮬레이션**에서 정상 비행, 배터리 부족, 긴급 상황을 선택합니다. 시작, 일시정지, 재개, 초기화를 지원하며 일시정지 중에는 0~120초 범위에서 시각을 선택할 수 있습니다. 20초부터 착륙을 요청하며, 긴급 시나리오에서는 30초부터 긴급 상태가 발생합니다.
- 사람, 차량, 착륙장 점유는 사이드바에서 설정합니다. 모델은 FOD만 자동 탐지합니다.

| 상태 | 의미 |
| --- | --- |
| 판단 확인 필요 | 최신 FOD 결과가 없거나 입력 및 판단 처리에 오류가 있음 |
| 요청 없음 | 유효한 탐지 결과가 있고 드론의 착륙 요청이 없음 |
| 접근 제한 | 착륙 요청 중 사람, 차량 또는 FOD가 있음 |
| 대기 | 위험요소가 없고 착륙장이 점유 중임 |
| 착륙 가능 | 착륙 요청 중 시뮬레이션 조건을 충족함 |

기체 경고는 긴급 상태면 **긴급**, 그 외 배터리 20% 미만이면 **주의**, 나머지는 **정상**입니다. 판단 근거, 경고와 권고 조치는 화면에서 함께 확인할 수 있습니다. 고도는 모니터링 지표입니다.

## 자동 사진 저장 및 이력

실시간 스트림에서 첫 유효 FOD 탐지가 발생하면 추론에 사용한 카메라 프레임에 박스, 클래스, 신뢰도를 그리고 `vertiport_dashboard/data/fod_snapshots/`에 JPEG로 저장합니다. 파일명은 한국 시간과 고유 식별자를 포함합니다. 같은 이름의 JSON에 수신 시각, 기체 ID, FOD 개수, 최고 신뢰도와 해당 프레임에 대한 착륙 판단을 기록합니다. 자동 저장 대상은 박스를 그린 실시간 프레임입니다.

같은 스트림에서 FOD가 계속 검출되면 개수가 변해도 사진은 한 장만 저장됩니다. 유효한 미탐지 결과가 3초 이상 연속으로 확인된 뒤 재탐지하면 새 사진을 저장합니다. 이 시간은 `video_detection.py`의 `SNAPSHOT_CLEAR_SECONDS`에서 조정할 수 있습니다. 영상 연결을 다시 시작하면 새로운 스트림으로 취급합니다.

이벤트 CSV는 `vertiport_dashboard/logs/event_log.csv`에 저장합니다. 이미지 분석, FOD 상태 변화, 착륙 판단 변경과 사진 저장을 기록합니다. 영상 중단이나 오류로 판단이 보류되면 해당 사유가 기록됩니다. 사진 저장 이벤트는 CSV의 기존 상세 열에 JPEG 파일명을 기록하고, 최근 이벤트 화면은 해당 이름의 JSON과 연결해 최고 신뢰도와 사진을 표시합니다. 최근 8건, 확장 영역에서 최근 30건을 확인할 수 있으며, **전체 이벤트 CSV 다운로드**도 제공됩니다.

**자동 저장된 FOD 탐지 사진**에는 최신 3장이 표시됩니다. 최신 사진은 **사진 크게 보기**로 열고, 이전 사진은 **전체 탐지 이력 및 사진 상세**에서 탐지 시각 순으로 선택합니다. 선택한 사진은 JPEG로 다운로드할 수 있습니다. 로컬에 저장된 사진과 메타데이터는 앱을 재시작한 뒤에도 조회됩니다.

## 현재 범위와 후속 연동

현재 화면은 단일 드론으로 동작합니다. `smart_vertiport/main.py`의 복수 드론 순위 계산은 별도 스크립트에 있습니다. `data/sample_state.json`은 예시 파일이며, 대시보드에는 외부 JSON 연동과 `live_state.json` 자동 갱신 기능이 없습니다. 실제 X500/Pixhawk 통신, MAVSDK 텔레메트리, Gazebo 연동과 착륙 제어도 구현 범위 밖입니다.

후속 작업에서는 X500/Pixhawk 또는 Gazebo의 텔레메트리를 MAVSDK 등으로 수신하는 입력 모듈을 추가할 수 있습니다. 먼저 기존 시뮬레이터가 반환하는 상태 필드에 매핑하고, 수신 시각과 연결 상태를 검증한 뒤 대시보드 판단 입력에 전달하는 방식입니다.

FOD 미탐지는 모델이 해당 이미지나 프레임에서 설정된 신뢰도 이상의 FOD를 찾지 못했다는 뜻입니다. 이 화면은 시뮬레이션용이며 실제 안전 및 착륙 허가의 근거로 사용하지 않습니다.
